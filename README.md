# Skilline Responsive Website

A responsive educational website built with **HTML, CSS, and JavaScript**. The project focuses on creating a structured, visually responsive frontend that adapts to different screen sizes.

## Features

* Responsive navigation
* Educational landing-page sections
* Responsive content layouts
* Responsive cards and components
* Flexible page sections
* Mobile-friendly layout
* Multiple CSS breakpoints
* JavaScript-based frontend interactions
* Desktop, tablet, and mobile adaptations

## Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layouts, Flexbox, and responsive design
* **JavaScript** — Frontend interactions

## Responsive Design

The website uses CSS media queries to adjust its layout for different screen sizes.

The project includes breakpoints for different viewport sizes, including:

* 1200px
* 992px
* 768px
* 600px

This allows the layout and components to adapt between desktop, tablet, and mobile screen sizes.

## How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in a browser.

No backend or database is required.

## Responsive Testing

For the best experience, test the website using different browser viewport sizes.

Browser Developer Tools can be used to simulate:

* Desktop screens
* Tablets
* Mobile phones
